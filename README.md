# State Management & Theming App

A React-based dashboard application demonstrating:

- Global state management using **Redux Toolkit**
- Custom theming using **React Context API**
- CSV export functionality
- Persistent selection of items across pages

## Installation & Project Setup

Follow the steps below to run the project locally:

### 1. Clone the Repository

git clone https://github.com/YuliaDemir/react.git

### 2. Navigate into the Project Folder

cd your-repo-name

### 3. Install Dependencies

npm install

### 4. Start the Development Server

npm run dev

## Run Tests with Coverage Report

npm run test:coverage
